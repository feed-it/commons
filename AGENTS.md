# AGENTS.md

## Commits

- Follow the [Angular commit convention](https://github.com/angular/angular/blob/main/contributing-docs/commit-message-guidelines.md): `type(scope): subject`
  - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`
- Subject only: **no body, no footer**.
- **No `Co-Authored-By`** line (or any other attribution trailer).
